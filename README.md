# WidgetCity

WidgetCity — ночной изометрический пиксельный город на рабочем столе Windows. Город размещается за значками, а настройки открываются через системный трей.

## Возможности

- Три размера города, предсказуемая генерация по сиду и живой предпросмотр. Масштаб и позиция сохраняются вместе с планировкой.
- Пять сценок с настраиваемыми привязками к запущенным программам, активным окнам, USB-накопителям, загрузкам и простою. Кнопка «Проверить» запускает сценку сразу.
- Музыкальная карточка над кафе с обложкой, названием, исполнителем и управлением медиасессией Windows. Источник можно закрепить в настройках.
- Проверка обновлений и установка новых сборок Windows из GitHub Releases.

## Запуск

[Скачайте WidgetCity.exe для Windows x64](https://github.com/xxxROX1xxx/WidgetCity/releases/latest/download/WidgetCity.exe) и запустите файл.

Для запуска из исходников нужны Windows с поддержкой PySide6 и медиасессий GSMTC и Python 3.10–3.14. На Windows 11 проверено с Python 3.14.

~~~powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m widgetcity
~~~

После установки зависимостей `start-widgetcity.cmd` запускает приложение без консоли. Закрытие настроек сворачивает приложение в системный трей. Команда «Выход» в трее завершает его.

## Обновление

Кнопка «Обновить» в верхней части настроек проверяет последний стабильный [релиз GitHub](https://github.com/xxxROX1xxx/WidgetCity/releases). Готовая сборка скачивает `WidgetCity.exe` и после подтверждения устанавливает его с перезапуском. В режиме запуска из исходников кнопка предлагает открыть страницу релиза.

Для выпуска новой версии обновите `__version__` в `widgetcity/__init__.py`, пересоберите приложение и приложите `dist\WidgetCity.exe` к GitHub Release с соответствующим тегом, например `v0.1.1`.

## Настройки

- **Город.** Размер определяет число кварталов, сид в диапазоне 0–999999 задаёт планировку. Масштаб изменяет размер виджета на экране. «Переместить» включает перетаскивание, «В угол» возвращает город вправо вниз.
- **Активности.** Выберите сценку, чтобы добавить, изменить или удалить условия. Можно выбрать запущенную программу, указать путь к `.exe` или ввести имя файла. Любой из привязанных триггеров запускает сценку. Кнопка «Проверить» сразу запускает её в городе и предпросмотре. По умолчанию фонарь телефонной станции мигает, пока запущен Discord, в том числе когда его окно свёрнуто.
- **Вокзал.** Слежение за выбранной папкой реагирует на новый или изменённый файл после стабилизации его размера и времени изменения. Временные файлы браузеров и содержимое папки на момент начала наблюдения игнорируются. Каждый завершённый файл добавляет одну коробку. Поезд ждёт, пока грузчик разнесёт коробки. Если поезд уже тронулся, грузчик доносит новые коробки с платформы.
- **Кафе.** Выберите текущую медиасессию Windows или закрепите приложение. Источник должен предоставлять Windows данные о треке и медиакоманды. Карточка и музыкальная подсветка настраиваются отдельно. Повторный клик по кафе или Esc закрывает карточку.

Город рисуется на рабочем столе за значками. Поверх рабочего стола открываются обычные окна. Свободная от значков часть кафе и открытая карточка принимают клики. В режиме перемещения можно перетащить город за всю его область. Положение, планировка и привязки сохраняются в пользовательском каталоге настроек Qt в файле `settings.json`.

## Сборка Windows x64

~~~powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
$widgetCitySprites = Join-Path $PWD 'widgetcity\sprites'
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --onefile --windowed --name WidgetCity --paths . --specpath build --icon "$widgetCitySprites\widgetcity.ico" --add-data "$($widgetCitySprites):widgetcity/sprites" widgetcity/__main__.py
~~~

Готовые спрайты хранятся в `widgetcity/sprites`. Для их перерисовки запустите `tools/draw_sprites.py` в окружении с Pillow.

## Тесты

~~~powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
~~~
